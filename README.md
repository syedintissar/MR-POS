# MR-POS: Mr Printer & Tuner

A local-first POS, inventory, accounting, service/repair and shop management system. It is a Laravel web app that runs on the shop's Windows server PC and is used from browsers on the shop LAN.

**Current status:** Phase 1 (analysis & design) is complete and awaiting owner review. No application code exists yet.
